# Frontend

This is the Flutter Web frontend for the Launch application.

## Structure

- **lib/main.dart** - Main Flutter Web app with sample UI
- **pubspec.yaml** - Flutter dependencies

## Development

```bash
# Run Flutter Web dev server
flutter run -d web

# Build for production
flutter build web --release
```

## Features

- Dashboard with employees list
- Restaurants list
- Backend API integration
- Material Design UI
